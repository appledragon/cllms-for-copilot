CLLMs for Copilot Chat uses your own provider API keys — Qwen (DashScope 国内 / International), z.ai GLM, MiniMax (国内 / International), Xiaomi MiMo, Moonshot (Kimi 国内 / International), and Tencent Hunyuan (混元) — to make those models available in the model picker.

Each provider keeps its own API key and endpoint. Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `CLLMs: Set API Key`: Set or update your API key
- `CLLMs: Clear API Key`: Remove your API key
- `CLLMs: Get API Key`: Open a provider API key page

> **Testing Status:** Domestic (国内) endpoints are fully tested and verified. International endpoints are not yet tested — they share the same API surface and should work, but haven't been confirmed. Test tokens and test reports are welcome! See the [README](https://github.com/appledragon/cllms-for-copilot#testing-status) for details.
