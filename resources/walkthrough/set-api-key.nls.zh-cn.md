CLLMs for Copilot Chat 使用你自己的各服务商 API Key —— Qwen（DashScope 国内 / International）、z.ai GLM、MiniMax（国内 / International）、小米 MiMo、Moonshot（Kimi 国内 / International）、腾讯混元 —— 让这些模型出现在模型选择器中。

每个服务商独立保存自己的 API Key 和端点。只需粘贴一次，之后可通过命令面板更新或移除。

- `Cmd/Ctrl + Shift + P`：打开命令面板
- `CLLMs: 设置 API Key`：设置或更新 API Key
- `CLLMs: 清除 API Key`：移除 API Key
- `CLLMs: 获取 API Key`：打开服务商的 API Key 页面

> **测试状态：** 国内站点均已测试通过。国际站点尚未测试——它们使用与国内站点相同的 API 接口，理论上可直接使用，但尚未实际验证。欢迎提供测试 token 或协助测试！详见 [README](https://github.com/appledragon/cllms-for-copilot#%E6%B5%8B%E8%AF%95%E7%8A%B6%E6%80%81)。
